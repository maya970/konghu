# 空毂

小团队比不过大钱包公司的检测、审计和应急。空毂不在那条路上加码，而是把签名核做成对攻击工具没用的东西。

名字来自车轮。辐条受力，毂是空的。空心不是装饰：毂里一旦塞满功能，偷钱包的程序就有东西可抓。清机保持空，浊机去碰链。

## 清机什么都不做，所以没东西可偷

常见盗钱包程序找的是浏览器插件、知名钱包目录、剪贴板里的助记词，以及一长串可以任意调用的签名接口。清机躲开这些，不是因为它更能发现病毒，而是因为这些接口它没有。

清机只做一件事：把一张固定形状的转账简牍，用自己的代码还原成交易，签完即忘掉种子。它不签对方传来的摘要。摘要一旦由浊机或网页决定，签名核就变成了通用签名神谕，后面加什么检查都是在补一个已经太大的洞。

简牍的形状是固定的，多一个字节就拒绝。上面只有这些字段：链编号、主币或一笔代币转账、收款地址、最小单位数量、费用封顶、过期时间、nonce、gas。EVM 主币的调用数据必须为空。代币只允许恰好是 `transfer(address,uint256)`。`approve` 写不进简牍，授权也就不会留在链上。没有会话、没有插件、没有自动更新、不显示链上给的名称、小数位和倒计时。那些字符串是对方提供的，用来让人看错。

清机不读登记表。屏幕上的链是编号，不是宣传名。任何合格的 EVM 简牍都能签，签名核不必认识这条链。

## 兼容放在可扔掉的那一侧

公开链里的绝大多数用的是同一套 EVM 签名，差别是链编号、小数位和节点。这些放在 [registry/evm.json](registry/evm.json)。加减一条 EVM 链只换这份文件，不动清机。

浊机联网，读登记，把人填的数量换算成最小单位，写成简牍，再把回执广播出去。这里没有种子，也不链接签名代码。它默认已经被改过。改简牍可以改收款人、数量和链，但不能让清机签出简牍形状之外的东西。

非 EVM 家族以后若要加，也是编进清机的纯函数，不是从磁盘加载的插件。插件是另一条可以换掉签名行为的路。

## 人确认的是自己的记录，不是窗口里的末几位

清机把简牍解析成链编号、最小单位数量、实际费用封顶和全长地址。签名前要输入确认串，而且不能粘贴：

- 主币：`链编号/数量/实际封顶/收款地址`
- 代币：`链编号/数量/实际封顶/代币合约/收款地址`

地址是 40 位十六进制，不带 `0x`。这串要按转账之前自己记下的数字来输，不要照着清机窗口抄。窗口上的字可以被挡住或换掉；自己记下的数量和全长地址不会因为对方换了一张简牍就自动变成新的。只核对末几位挡不住特意凑出来的地址，也盖不住数量。

回执经投递目录交回，不经剪贴板，不经进程通信。浊机只广播和自己写出的那张简牍一致、而且交易字段也对得上的回执。写出文件时不跟随符号链接。

## 病毒挡在账户，不挡在花招

口令只加密本机的熵，不是助记词的第 25 个词。派生参数写死：Argon2id，19 MiB，2 次迭代。一份被换掉的保险库不能要求更大的内存，也不能把派生改弱。助记词只在清机窗口出现一次。

同一用户下的程序仍可能在解锁的那几秒读到清机的内存。所以清机和浊机分属两个普通账户，都不是管理员。清机不做反调试，不挂钩，不扫描别的进程。已经是管理员、并且能在解锁瞬间读内存的程序，不在这版能挡住的范围内。把检测做进签名核，只会让核重新变满。

## 使用

两个程序：

- `qing` 清机。用户自己打开。只签名。
- `zhuo` 浊机。联网、写简牍、广播回执。

```bat
cargo build --release -p qing -p zhuo
```

GNU 工具链需要 `as.exe` 在 PATH 里。工程目录含中文时，把 `CARGO_TARGET_DIR` 设到纯英文路径再编译。`registry\evm.json` 放在浊机旁边，或在仓库目录里运行浊机。清机不需要这份文件。

1. 建两个本地普通账户。只让清机账户跑清机，日常账户跑浊机。
2. 投递目录只给这两个账户改文件：

```bat
mkdir C:\KonghuDrop
icacls C:\KonghuDrop /inheritance:r
icacls C:\KonghuDrop /grant:r qinguser:(OI)(CI)M
icacls C:\KonghuDrop /grant:r %USERNAME%:(OI)(CI)M
```

3. 禁止清机出网。路径换成清机 exe 的实际位置：

```bat
netsh advfirewall firewall add rule name="Konghu Qing deny out" dir=out action=block program="D:\path\to\qing.exe" enable=yes
```

4. `runas /user:qinguser qing.exe`。保险库在该账户的 `%USERPROFILE%\.konghu\vault.khuv`。浊机的设置在日常账户的 `%USERPROFILE%\.konghu-zhuo\`。
5. 清机创建保险库，抄下助记词，锁定。解锁后把付款地址抄进浊机。两边的投递目录都填 `C:\KonghuDrop`。
6. 浊机写入简牍。数量在浊机按小数位换算，在清机只显示最小单位，以清机上的整数为准。
7. 清机按自己的记录输入确认串并签名。签完种子即从内存清掉。浊机广播回执，窗口给出交易哈希，程序不会打开浏览器。

本地备注在清机账户的 `%USERPROFILE%\.konghu\labels.txt`，一行一个：`40位十六进制地址` 空格 `备注`。备注只来自这个文件。含双向覆盖、零宽字符或控制字符的备注会被丢掉。
